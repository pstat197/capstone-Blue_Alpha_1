# capstone-Blue_Alpha_1
Group 12 - Prior Sensitivity Analysis Framework

A Bayesian prior sensitivity analysis framework for Marketing Mix Models (MMM). This project systematically perturbs prior specifications and measures how sensitive key MMM outputs—such as ROI estimates and channel contributions—are to prior assumptions. The goal is to help analysts and stakeholders understand which conclusions are robust and which depend heavily on modeling choices.
